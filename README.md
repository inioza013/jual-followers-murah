# JFM — JUAL FOLLOWERS MURAH

Website katalog awal JFM dengan tema Midnight Blue + Electric Blue.

## Status saat ini
- Halaman katalog dan harga.
- Formulir permintaan konfirmasi yang diarahkan ke WhatsApp admin.
- Estimasi total dihitung di browser.
- Belum ada backend, database pesanan, pembayaran QRIS/transfer otomatis, pelacakan pesanan, maupun panel admin privat.

## Publikasi GitHub Pages
Di repository GitHub buka **Settings → Pages**. Pada bagian **Build and deployment**, pilih **Deploy from a branch**, pilih branch **main** dan folder **/(root)**, lalu **Save**. Tunggu proses deployment selesai.

## Sebelum transaksi diaktifkan
1. Verifikasi pemasok dan ketersediaan layanan.
2. Tinjau ketentuan masing-masing platform dan hukum yang berlaku; jangan membuat klaim hasil atau retensi yang tidak dapat dibuktikan.
3. Tambahkan backend dan database untuk order tracking.
4. Tambahkan payment gateway resmi dengan verifikasi webhook di server.
5. Tambahkan autentikasi admin yang aman.

Jangan meminta atau menyimpan password akun media sosial maupun kode OTP pelanggan.
